# 运行统计树表第一版实施记录

日期：2026-10-10。依据 [展示设计](database-runtime-tree-display-design-20261010.md) 实施。

## 用户可见行为

运行统计现在通过独立树表展示，编辑器与预览共用 `DatabaseRuntimeTable.vue`。分类名称尽量中文化；顶层分类没有统计值时显示“—”。点击左侧箭头，用接口返回的真实行标识继续查询子级，逐层显示对应统计值。不会从显示名称或 SQL 文本拼接条件，不把不同维度合计或混合排名。

编辑数据弹窗取消运行统计的指标选择，改为说明默认展示列：分组名称、平均最终响应、平均首包响应、查询速率、返回数据速率、影响行数速率。内部仍通过既有配置片段保存默认字段，旧运行统计配置可直接进入树表；点击确定后保存默认列配置。

节点和查询时间沿用原有控件。数量显示为“每组 Top N”；顶层维度数不代表该参数是否生效。排序选择用于下钻请求及同级子行排序；可选搜索文本透传现有接口的 `search` 参数。

支持收起、缓存再展开、子级加载状态、失败重试和合法空子级提示；零值保留，缺失值不补零。刷新可更新当前展开分支，并保留同一区间的展开位置。节点、时间或查询配置变化后清理旧缓存，迟到响应不会覆盖新状态。原页面定时刷新已接入该组件。

综合运行统计在柱状图、构成图、堆叠图、趋势图和单值图中置灰，并提示使用树表；专门的实例、应用、命令等分析保持原行为。

## 请求、样式与隐私

根和子级均使用既有 `getRawTable` 接口及现有平台代理。子级用独立的临时 `rawSelection` 条件，避免给服务端返回的完整选择条件再加节点前缀或重复解码。它不写入用户大屏的持久配置。真实查询目标仍为 236，没有改变平台认证和代理配置。

树表只保留当前组件的临时数据，不把展开所得的行标识和 SQL 数据写入 `widgetdata`。文本按纯文本显示，保留比较符号；SQL 长名称可省略并通过提示查看。验收只展开查询命令相关路径，日志记录请求类型、时间、数量、行数和数值单元格数量，不记录 Cookie、密码、SQL 正文或完整选择条件。截图收起了可能包含 SQL 正文的深层分支。

第一版提供固定默认列，不含高级列显隐管理；已有普通表格继续使用原来的渲染路径。运行统计树表的高级阈值着色和所有列宽样式配置尚未做专项验收。

## 验证结果

- 数据库及平台会话回归：15 个测试文件、161 项全部通过；修改的数据库模块、树表组件、字段组件和新增测试通过 ESLint，相关 Vue 模板编译无错误。
- 新增测试验证默认列、两级展开、服务端选择条件原样使用、缺失/零值、同名条目不合并、空结果、失败重试、分支缓存、过期响应、固定时间与页面时间、配置重开，以及原页面刷新和展开位置恢复。
- 完整生产 webpack 配置的隔离构建通过。产物在 `backups/runtime-tree-v1-20261010/production-build`，没有覆盖原生产 dist 或在生产 static 中加入验收文件。
- 当前真实验收包含数据库/数据库客户端 × 编辑器/预览四个用例，全部 PASS。所选数据库节点的命令分组返回 3 个子项、15 个有效数值单元格；客户端返回 4 个子项、20 个有效数值单元格。两类对象的第二级查询均返回 10 行。
- 在所选数据库命令分组中，将每组数量改为 2，实际返回 2 个子项。该结果只证明所测分组的数量参数生效，不代表所有维度与排序组合都已验证。

实测区间为北京时间 2026-10-09 00:00 至 2026-10-10 00:00。每轮四用例共 16 次请求，全部向 236；包含两个节点候选请求、各页的根/子级/第二级查询，以及数据库编辑器的数量调整探测。截图和真实结果采用页面源代码中的同一个树表组件，而非单独重写的展示模型。

深层验收只核对响应结构与行数，没有检查或保存语句正文；SQL 分支的正文由用户按权限自行查看。搜索匹配口径、全部排序选项、所有维度、任意深度与全部时段尚未逐项实测。配置重开通过回归验证，本次没有代用户保存后端大屏、执行导出导入或部署远程生产环境。
