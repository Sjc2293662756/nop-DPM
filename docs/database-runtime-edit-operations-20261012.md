# 运行统计表编辑操作恢复

日期：2026-10-12。

上一版把移动限制在标题文字，并让内容区的 mousedown 提前返回，原来依赖 mouseup 的右键菜单未得到触发。用户报告无法直接移动、删除。此次先增加两项编辑器交互回归：单元格和标题空白拖动、右键菜单与删除确认；修复前两项均失败。

编辑器现在根据鼠标目标区分操作：

- 左键按住标题区域（包括空白）或表体单元格，可直接移动表格。
- 展开箭头、刷新和重试按钮，以及表头调宽、滚动区域继续处理各自交互，不启动组件拖拽。
- 在运行统计任意位置右键，先选中对应组件，再打开原有置顶、置底、删除菜单。右键不会安装移动监听。删除仍进入原确认框。
- 单独选中运行统计时保留遮罩穿透，缩放手柄继续可用；多选和普通组件保持原处理路径。预览不出现编辑提示。

## 验证

真实编辑器 `/#/imgeditor?id=45` 验证了右键菜单，点击删除打开确认框后选择取消，表格仍存在。通过实际拖动单元格，组件从左 40 / 上 99 移至左 61 / 上 109，随后恢复为左 40 / 上 99。最后展开查询命令并打开右键菜单，显示 14 行，确认展开与编辑操作同时可用。未确认删除现有表格，也未保存或发布后端大屏。

回归验证标题与单元格拖动、按钮点击、滚动与表头事件、缩放与多选移动、右键选中、删除确认、取消和确认后的隐藏逻辑。确认删除仅在模拟数据的自动回归中执行。数据库和平台会话共 15 个测试文件、165 项通过；树表组件与测试 ESLint 通过。
