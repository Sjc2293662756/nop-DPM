# 纵向柱状图数据库多指标适配

日期：2026-10-10。组件：`zongxiangzhuzhuangtu`。

**历史试验，已按用户决定撤回。**同日用户要求与网络普通柱状图的指标数量保持一致，当前已恢复最多一个指标。当前规则见 [数量对齐记录](database-vertical-bar-network-alignment-20261010.md)；下文保留当时的多指标实现和验收结果，不代表当前开放能力。

**运行统计验收范围纠正：**下文运行统计 PASS 仅检查顶层响应映射，没有验收下钻后的子级统计值。该分析实际为树表，目前尚未完整适配，见 [运行统计树表设计](database-runtime-tree-display-design-20261010.md)。

纵向柱状图现已开放多个数据库数值指标选择。每个指标单独形成一条系列，按不同默认颜色并排展示；不堆叠、不相加、不将平均值合计为总量。此改动由用户对单指标限制的反馈触发，替代上一轮该组件的单指标规则。

## 选择和绘图规则

- 数据库指标下拉支持多选，不再限制为一项；选择范围仍由当前分析内容的有效字段决定，文本和时间不作为柱高。
- 默认仍选择一个指标。已有单指标配置保持原来的显示；需要时可追加指标。
- 所有系列共用真实返回的分类名称和分类顺序，按首个显示指标降序排列。其余指标随同一行移动，不独立排序，不合并同名分类。
- 每条系列保存自己的数值、单位和颜色。新系列添加不同默认颜色；已有系列的样式仍可编辑。图例显示各指标，并支持点击筛选。
- 根据响应实际单位分配数值轴：同单位共轴，不同单位分别标轴。未提供单位的指标各用独立轴，避免推测其可比性。
- 提示框逐项显示指标名称、实际值和各自单位；零值保留，缺失值保持 `null` 并明确提示。缺失统计覆盖全部选中指标，不因首个指标缺失而丢弃其他有效指标。
- 编辑器和预览复用相同路径；保留此前页面时间/固定时间、错误恢复、迟到响应保护和静态数据切换行为。
- 多个指标会增加柱子及数值轴的数量；图例筛选和调整组件尺寸可帮助查看较多指标。

当前分析范围保持上一轮开放状态：节点统计、实例、应用、命令、运行统计；数据库客户端另有访问的数据库。慢事务排名、语句级可视化和时间柱状图仍未开放。横向柱状图、饼图、单值组件和堆叠组件继续采用原来的指标限制，本轮没有给它们开放多指标。

## 请求和保存

多选指标仍保存在既有版本化 URL 配置片段的 `metrics[]` 中，不增加后端配置字段。重开弹窗保留全部选择。节点统计、访问的数据库及运行统计按所选指标构建请求；实例、应用和命令仍使用固定请求字段 `FINAL_RESP_TIME,DB_INSTANCE,QUERY_TEXT`，显示指标独立保存。

后端请求仍通过原平台代理查询 236，指标目录仍在前端定义；没有改动认证、代理目标或后端指标目录接口。运行统计的接口数量限制沿用此前说明：请求 `top` 参数不保证返回行数上限，按实际返回分类绘制。
